# KIDO — frontend

App web React + Vite + TypeScript + Tailwind (direction visuelle Apple × Netflix/Disney+).

Voir le README à la racine du projet (`../README.md`) pour l'installation, les variables d'environnement et le déploiement.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # build de production dans dist/
```
